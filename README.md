# Менеджер задач (Task Manager)

## Опис проєкту

Менеджер задач — це програма, створена мовою Python, яка допомагає користувачу організовувати свої щоденні завдання. Програма має систему входу за головним паролем та автоматично зберігає всі завдання у JSON-файлі.

## Функціональні можливості

- 🔐 Захист програми головним паролем.
- 🔑 Перевірка надійності пароля.
- 🎲 Генерація надійного пароля.
- 🚫 Блокування доступу після трьох неправильних спроб входу.
- ➕ Додавання нових завдань.
- 📋 Перегляд списку завдань.
- ❌ Видалення завдань.
- ✅ Позначення завдань як виконаних.
- 🔄 Зміна головного пароля.
- 💾 Автоматичне збереження завдань у JSON-файлі.
- 🛡️ Перевірка неправильного введення користувача.

## Використані технології

- Python 3
- JSON
- Модуль `json`
- Модуль `random`
- Git
- GitHub

## Інструкція із запуску

1. Завантажити або скопіювати репозиторій на комп'ютер.
2. Відкрити папку проєкту у VS Code або Cursor.
3. Відкрити термінал.
4. Виконати команду:

```
python task_manager.py
```

5. Створити головний пароль та увійти до програми.
